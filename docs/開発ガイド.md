# 開発ガイド

企画書は `README.md`。ここには実装を始めるための実務的な情報だけを書く。

## 動かし方

```
npm install
npm run dev
```

`http://localhost:5173` を開く。ビルド確認は `npm run build`、lintは `npm run lint`。

## 誰がどのファイルを触るか

| 担当 | 主に触るファイル | やること |
|---|---|---|
| **A** | `src/components/PostForm.tsx` | 投稿フォームの見た目・入力チェックの改善 |
| **B** | `src/components/Timeline.tsx`<br>`src/components/LabelFilterBar.tsx`<br>`src/lib/timelineFilter.ts` | 絞り込みの挙動の調整 |
| **C** | `src/components/ReplyThread.tsx`<br>`src/components/ViewerSwitcher.tsx`<br>`src/lib/replyVisibility.ts`<br>`src/lib/timelineMix.ts` | 混ぜ方の工夫、非公開判定の調整 |
| **D** | `src/types.ts`<br>`src/data/*`<br>`src/lib/storage.ts`<br>`src/context/ViewerContext.tsx`<br>`src/App.tsx` | 型・サンプルデータ・全体の配線。他の3人から相談を受ける役 |

ファイルの担当は目安であって、所有権ではない。困ったら直接触ってよい。

## 全体の仕組み

```
App.tsx
 ├─ ViewerProvider          … 「誰として見るか」を全体に配る（企画書 §10）
 ├─ AnnouncementBanner      … お知らせ。ラベルを一切見ない（企画書 §6）
 ├─ PostForm                … 投稿フォーム（企画書 §3）
 └─ Timeline
     ├─ LabelFilterBar      … ラベルの絞り込みボタン（企画書 §4, §5）
     └─ PostCard（投稿ごと）
         └─ ReplyThread     … 返信の表示・投稿（企画書 §7）
```

データの流れ：

1. `src/data/*.ts` に最初のサンプルデータがある
2. 初回だけ `localStorage` に書き込まれ、以降はそこから読む（`src/lib/storage.ts`）
3. 投稿・返信の追加や状態変更は `usePosts` / `useReplies`（`src/hooks/`）を通す
4. 表示直前に `timelineFilter.ts`（ラベル絞り込み）→ `timelineMix.ts`（範囲外を混ぜる）の順で並び替える

## 型とサンプルデータ

`src/types.ts` が企画書 付録B の ER 図をそのまま型にしたもの。テーブルを増やす／列を増やすときは、まず付録Bの図を直してからここを直す。

`USER_LABEL` と `POST_TAG` は独立した配列ではなく `User.labelIds` / `Post.tagLabelIds` に畳んである。中間テーブルの行そのものが必要になったら、そのとき型を戻す。

## 動作確認のコツ

- 画面右上の「あなたは○○として見ています」で視点を切り替えると、非公開の返信の見え方が変わる（`p1` の教科書に非公開の返信を2件、サンプルとして入れてある）
- 「サンプルデータに戻す」ボタンで、書いた投稿・返信を消して最初の状態に戻せる
- ラベルを1つも選んでいない状態は「すべて表示」（企画書 §5）。ラベルを選ぶと絞り込まれ、選んだ数が1つ以上のときだけ「範囲外の投稿を混ぜる」のチェックボックスが出る
